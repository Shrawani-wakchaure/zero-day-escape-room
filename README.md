# The Zero-Day Escape Room 🕵️‍♂️🐾

A cybersecurity and digital forensics text/puzzle adventure web game styled entirely like a **Vintage Detective Case File / Cold Case Archive**.

---

## 🔍 Features

- **Multiple Selectable Escape Rooms**: Intro dashboard with 3 distinct incident dossiers (Cloud Breach, Industrial SCADA, Financial Mainframe).
- **4 Forensic Puzzle Rooms**:
  1. 🔍 **Log Forensics**: Detect anomalous IP & directory traversal probes.
  2. 🛡️ **Security Policy**: Audit and harden IAM & authentication policies.
  3. ⚙️ **Crypto Tunnel**: Reconstruct secure TLS ciphers & key exchanges.
  4. 💻 **Zero-Day Patch**: Identify and apply regression-tested secure code fixes.
- **Inspector Whiskers (Detective Cat)**: Interactive desk companion providing feline forensic hints, synthesized meows, and purrs.
- **Authentic Vintage Aesthetic**: Aged parchment documents, manila folders, brass chronometer timer, distress ink rubber stamps, and 100% offline Web Audio sound effects.

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Run the Game
```bash
python app.py
```
Open **[http://localhost:5555](http://localhost:5555)** in your browser.

## 🧪 Run Tests

